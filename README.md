# SELF BALANCING ROBOT
This project involves building a self-balancing robot using an Esp32 microcontroller. The robot uses sensors to detect its orientation and adjusts its motors to maintain balance.

## Components Used
- Esp32 Microcontroller
- MPU6050 Gyroscope and Accelerometer
- A4988 Motor Driver
- Stepper Motors NEMA 17
- Power Supply (Battery) 12V 2A
- PCB Board

## Features
- Real-time balancing using sensor data
- Motor control for movement and balance
- Compact and efficient design
- Easy to assemble and program

## Installation
1. Clone the repository to your local machine.
   ```
   git clone
    ```
2. Install the required libraries for the Esp32 and MPU6050.
3. Connect the components as per the wiring diagram provided in the repository.
4. Upload the code to the Esp32 using Arduino IDE or any compatible platform.\
5. Power on the robot and test its balancing capabilities.
6. Adjust the PID parameters in the code for optimal performance.
